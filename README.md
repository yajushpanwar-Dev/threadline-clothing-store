# THREADLINE — Clothing Store Demo

A responsive clothing-store front end built with plain HTML, CSS and JavaScript.

## Run locally
1. Clone or download this repository.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Internet is needed for the Google Fonts and Unsplash product photos.

## Features
- Responsive layout for desktop and mobile
- Product cards and category filters
- Search and price sorting
- Add-to-bag interactions, quantity controls and subtotal
- Newsletter demo form and checkout information modal

## Notes
This is a front-end college/demo project. The cart is stored only in page memory and resets on refresh. Checkout, newsletter signup, inventory, accounts and payments are not connected to a backend. Product images are loaded from Unsplash URLs.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — product data and interactions
